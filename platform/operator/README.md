# Private local operator console

From the platform directory run `node operator/console.mjs`. Open the loopback address printed in the terminal and enter its one-time code. The code stays out of URLs, logs from user requests, and the public web app. Closing the process invalidates its sessions. Closing the tab or signing out ends access from that tab. Restart the console for a new code.

Choose a UTC board to review its staffing allowance and submission queue. A submitted score and reason are final. An identical retry recovers the original decision. Lowering capacity preserves admitted work. These controls act on the same local SQLite data as the reference server. The console provides no chain signer, shell command endpoint, external publishing operation or production admin session.
