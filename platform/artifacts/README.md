# Private exact-byte artifacts

`ArtifactStore` stores bounded private evidence before a repository commits its reference. Keys are `private/{sha256}.json` or `.bin`; every read verifies length and SHA-256, and every retry checks the existing bytes before reporting `exists`. The 256 KiB limit is an application bound, not a Cloudflare quota. Invalid inputs throw before I/O; conflicting stored bytes throw `ArtifactConflictError` on put and return `conflict` on read. A write with an ambiguous transport result returns `unknown` with the unchanged identity. A read transport failure remains an exception. Callers must persist a reference only after `created`, `exists` or a verified reconciliation.

Node writes the original bytes to an exclusive private staging file, syncs it, and publishes through a create-only hard link. This prevents a concurrent replay from observing an incomplete target. R2 uses `If-None-Match: *`, verifies the checksum on upload, then reads back and hashes the body. Both adapters leave conflicting targets untouched. An object whose subsequent database reference failed remains available through its identity after restart. No adapter registers `manifest_catalog`, exposes an HTTP route, lists a bucket, or deletes a final object.

`semanticDigest` is separate caller provenance, format checked but not asserted as an interpretation of the bytes. The store verifies the exact-byte commitment; domain semantic verification remains the caller's responsibility. Node filesystem access inherits the local account's OS protection (POSIX modes are requested where supported); private object prefixes are not a substitute for an authorization boundary. Use only the local private root/binding in this implementation phase.

R2 behavior follows the [Workers API reference](https://developers.cloudflare.com/r2/api/workers/workers-api-reference/) retrieved 6 November 2026: conditional put returns null when the condition fails; supplied SHA-256 verifies uploaded bytes. Tests exercise the pinned Miniflare/workerd implementation, not a remote bucket.
