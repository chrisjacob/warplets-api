# Immutable exact-byte artifacts

`ArtifactStore` stores bounded evidence and public bundles before a repository commits their references. Private keys are `private/{sha256}.json` or `.bin`, bounded to 256 KiB. Public JSON keys are `public/{sha256}.json`, bounded to 2 MiB. These are application bounds, not Cloudflare quotas. Every read verifies length and SHA-256, and every retry checks existing bytes before reporting `exists`. Invalid inputs throw before I/O; conflicting stored bytes throw `ArtifactConflictError` on put and return `conflict` on read. A write with an ambiguous transport result returns `unknown` with the unchanged identity. A read transport failure remains an exception. Callers must persist a reference only after verified readback.

Node writes original bytes to an exclusive staging file in the selected namespace, syncs it, and publishes through a create-only hard link. This prevents a concurrent replay from observing an incomplete target. R2 uses `If-None-Match: *`, verifies the checksum on upload, then reads back and hashes the body. Both adapters leave conflicting targets untouched. An object whose subsequent database reference failed remains available through its identity after restart. No adapter registers `manifest_catalog`, exposes an HTTP route, lists a bucket, or deletes a final object. The private reference service still requires `privateIdentity`; broadening storage never authorizes a private reference to publish public bytes.

`semanticDigest` is separate caller provenance, format checked but not asserted as an interpretation of the bytes. The store verifies the exact-byte commitment; domain semantic verification remains the caller's responsibility. Node filesystem access inherits the local account's OS protection (POSIX modes are requested where supported); private object prefixes are not a substitute for an authorization boundary. All adapters here use local roots and bindings.

`createManifestCodec({crypto})` builds a public allowlist from committed board and allocation projections. Its canonical object bytes encode the existing `{sha256,manifest}` bundle. `sha256` and `semanticDigest` retain the historical manifest commitment; `byteDigest` identifies the complete object bytes. Verification requires an independently pinned semantic digest and can also require a pinned byte digest. Both sync legacy wrappers and the async codec execute the same portable commitment operations. Award proofs and allocation digests therefore retain the existing formats. The codec verifies award conservation, capped shares, original activation-relative dates and the supply policy: a positive u64 divisible by 200. Financial execution remains disabled; a verified declared burn is not proof of an on-chain burn.

R2 behavior follows the [Workers API reference](https://developers.cloudflare.com/r2/api/workers/workers-api-reference/) retrieved 6 November 2026: conditional put returns null when the condition fails; supplied SHA-256 verifies uploaded bytes. Tests exercise the pinned Miniflare/workerd implementation, not a remote bucket.
