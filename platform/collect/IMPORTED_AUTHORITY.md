# Imported collection command and read compatibility

This local fixture path consumes a committed `collection.adopt-legacy-source.v1` certificate. It does not publish an import endpoint or enable financial execution.

Stage publication and mint admission resolve accepted idempotency receipts first. Fresh work verifies the retained certificate, original source root, imported stage command receipts, and complete combined historical/current counters before loading the larger policy context. Only compact counts and the certificate/source fence survive that verification. The context and final atomic claim must agree on the source revision, recovery generation/watermark, authority revision, and accepted activation receipt. Fresh command time cannot precede activation.

Mint counters combine immutable historical anchors with new 045 admissions and 046 fulfillments. Founder cost uses BigInt multiplication of independently checked counts and exact immutable stage cost; money is never summed with SQLite numeric arithmetic. Imported originals remain historical anchors, without invented old admission/fulfillment receipts. New commands retain their current receipts and clock. Missing or contradictory import evidence holds fresh work.

Inventory projections already count the original and new Collect operation rows, so anchors are not added again. Imported availability requires the authority reader and its injected crypto adapter. List pages include at most one imported inventory, retain the contiguous sorted prefix, and use its final included ID as cursor. This bounds verification without dropping the next inventory. Node and Worker composition supply the appropriate existing crypto adapter.

Acceptance includes actual prepared/activated Node histories, imported open-stage minting, new stage publication, a concurrent final stage slot, accepted replay after close/revocation/pause, source races, omitted-child rollback, and mixed/all-imported cursor traversal. The local D1 test copies genuinely accepted Node rows through an explicitly synthetic private fixture nonce, then runs real D1 commands and reads. That copy is not a verified recovery claim; genuine D1 activation is tested separately by the activation slice. Historical source labels remain synthetic; no original operator authentication, payment proof, chain completeness, or production launch is inferred.
