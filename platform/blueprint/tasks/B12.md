# B12 — Scoped local operator commands and audit

**Dependencies:** B06 and B11. **Outcome:** one explicit local operator boundary drives the tested Earn and collection services, with narrow permissions, immutable receipts and auditable publication decisions. **PRD:** §§7–9, 12.3, 14–15, 19; A35, A37–A38, A41–A46, A56/A58. Detail: [product/collections design](../design/product-collections.md), P3/P7 and cross-track interfaces.

## Inspect and own

Inspect `platform/operator/{console,ui,console.test,browser-qa}.mjs`, `platform/operator/index.html`, `platform/operations/{controls,audit}.mjs`, `platform/earn/{workflow,operations}.mjs`, `platform/collect/operator.mjs`, `platform/governance/ballots.mjs`, plus B06/B11 service ports and audit-head repository.

Own proposed `platform/application/operator-commands.mjs`, `platform/operator/command-transport.mjs`, `platform/operator/commands.test.mjs` and corresponding private UI. Coordinate permission/audit schemas and migration numbers. Preserve the existing public/member router separation; do not add a generic public `/admin` endpoint or shell/SQL passthrough.

## Ordered implementation

1. Enumerate exact command kinds and scopes: staffing/admission policy, final moderation, future action configuration, collection draft/whitelist validation, stage publication, free-snapshot acceptance, advisory final decision, fixture observation and scoped pause. Keep founder backstop/public-stage decisions explicit. Operator approval in a fixture does not authorize spending or on-chain execution.
2. Adapt the existing loopback one-time-code session to a typed operator principal with bounded expiry, allowed command set and revocation. Member wallet sessions never satisfy this boundary. Do not assume this local scheme is a production identity provider.
3. Validate a discriminated command body and expected config/version before calling a service. Principal, operation kind, business identity, idempotency key and canonical digest bind the command. Return exact read-only preview before consequential local publication: price, source/terms digest, opening/cut, counts, affected scope and cost uncertainty.
4. Commit business transition, audit-head CAS and receipt together through the repository. Independent commands must not fork the audit chain. Identical accepted replay returns its original result despite a later pause; changed-body retry fails. Scoring/eligibility finality is preserved, not exposed as an editable moderation form after publication.
5. Show held evidence separately from rejected content, capacity separately from reward ranking and fixture priced-stage allocations separately from revenue. A free snapshot always targets `stage.opensAt`; UI acceptance time cannot choose its boundary. Hide reconstructing pre-reveal outcome fields from ordinary operator exports intended for publication.
6. Add focused console screens for these verified local commands, evidence references and receipts. Keep unavailable features visibly unavailable. Export an approval packet without publishing externally. No notification delivery, arbitrary fetch, provider purchase or wallet signer is added.

Run `node --test platform/operator/console.test.mjs platform/operator/commands.test.mjs` after the proposed test exists; B06/B11 focused service tests; installed-browser `node platform/operator/browser-qa.mjs`. Verify keyboard/error/focus behavior at 360/390/768/1440px and logout/reload. No real credentials or user-wallet signatures are required.

## Completion, limits and recovery

Evidence includes command/scope matrix, exact assertions, source commit, audit-chain verification and screenshots. No remote Cloudflare state/resources, production operator session, spending, signing, new authority probes or deployment. Hosted operator identity and independent audit retention remain release gates.

Rollback revokes operator sessions and pauses new commands; retain append-only audit and accepted receipts. Never roll back by editing a final score, replacing a published whitelist or discarding an unknown observation. Recovery proceeds through the same typed service with explicit evidence.
