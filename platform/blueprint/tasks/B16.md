# B16 — Complete cost packets and operation readiness

**Dependencies:** B13 and B15. **Priority:** financial preparation. **Mode:** strictly local.

## Outcome and requirements

Bind the existing fourteen-scenario cost calculator to named unsigned action plans and operational usage evidence. Produce an honest readiness report with separate complete, reference-only, missing and expired terms. Display peak upfront cash, consumed cost and expected refundable capital separately. No quote, threshold or founder-budget field authorizes payment.

Preserve PRD §15 and the existing policy: target below US$10 and within 20% of verified cash, later explicit exception up to US$30, combined new recurring ceiling US$5/month, 80% warning, advisory 50% reserve. Unknown nonzero costs prevent a complete packet. Gross 5% farm funding is token supply allocation, not founder SOL cost. Token marks and unsold NFTs are not cash receipts.

## Ordered implementation

1. Enumerate every required account, instruction and fulfillment branch for the selected unsigned plan. Bind network, slot, program/configuration hash, instruction/message hash, funding-state hash, simulation reference, blockhash when applicable and validity interval to the existing context ID.
2. Attach each nonzero cost's exact count, payer, denomination, account size/existence, additional rent, source, observation/expiry and context. Preserve `reference`, `hypothetical`, `quoted`, `upper-bound` and `product-policy`. A policy price does not quote fulfillment costs. Never promote old reference amounts by changing their timestamp.
3. Add an operation dependency graph for cashflow. Count shared account setup once. Budget temporary-account rent upfront and expected refund separately; the existing Vault fixture prepares that account before its atomic payout. Sequential reuse can reduce peak float only when closure is established; concurrent operations need concurrent funding. Interrupted preparation retains a cleanup/float liability.
4. Build first-ATT, one-claim, one-mint and monthly comparisons from disjoint terms. Include all promised reward/reserve setup before the first production ATT, including unminted inventory. Price a legitimately empty first board as its recorded 1% burn branch, not a recipient root; keep later mandatory costs visible. A pending board is neither branch completed.
5. Apply fresh SOL/USD and OG/USD conversion with expense ceilings rounded up and receipts down. Unknown conversion leaves fiat totals unavailable. Gross reward funding, protocol deductions, user net and company collectible fees remain separate.
6. Join B13 quota/commitment state and show scenario completeness separately from spend review and protocol readiness. Optional-work limits must not erase claims, withdrawals, accepted reconciliation or proof retention. A complete local fixture cannot set a financial capability flag.
