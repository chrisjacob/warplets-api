# B01 — Extract portable application services and cryptography

**Depends on:** B00. **PRD:** §§11–13; A35, A36, A37, A38. **Owner:** application/contracts implementer; coordinator reviews shared interfaces. This card and [CONTRACTS](../CONTRACTS.md) control the supporting [storage design](../design/storage-earn.md).

## Outcome and inspection

Expose the existing Node Earn behavior through injected application ports, preserving exact results and historical commitment bytes. Do not rewrite financial algorithms or enable another route yet. Inspect `platform/earn/{workflow,components,positions,checks,commitments,verifiers}.mjs`, `platform/pricing/{policy,evidence,fixtures}.mjs`, `platform/operations/audit.mjs`, `platform/storage/database.mjs`, `platform/server/application.mjs`, `platform/security/ed25519.mjs` and current contract tests. See storage-design sections **AE-01** and **Port signatures to freeze before parallel implementation**.

Proposed ownership: `platform/application/{ports.ts,context.mjs}`, `platform/earn/service.mjs`, `platform/storage/node/earn-repository.mjs`, portable canonical encoders and runtime crypto adapters. Existing pure `.mjs` domain files remain authoritative. New ports and Worker adapters use TypeScript; no wholesale language migration.

## Implementation sequence

1. Record golden input/output vectors from existing tests: ranked boards, allocation windows, capped amounts, semantic commitments, inclusion proofs and configuration hashes. Preserve byte ordering, purpose prefixes, encoding and numeric representation.
2. Define the single `ApplicationContext` and named Promise-returning commands in CONTRACTS. Freeze command identity, expected revisions, result unions and principal ownership before parallel work. Persistence methods return DTOs, not driver rows; handlers receive no arbitrary SQL or transaction callback.
3. Separate pure validation/canonical byte production from Node hashing. Implement SHA-256/strict Ed25519 adapters using installed capabilities. Preserve existing weak/noncanonical encoding checks. Tests generate disposable keys only; no production key reads or new security probes.
4. Extract Node repository calls behind the ports without introducing `await` inside the existing synchronous SQLite transaction callback. Service orchestration may await completed repository operations; domain ranking/math remains synchronous.
5. Isolate `recordStakeRead()` and other synthetic seeds in a test/demo adapter. Hosted application imports must not pull fixture bootstrap, filesystem, `node:sqlite` or implicit external provider access into workerd.
6. Keep existing CLI signatures through compatibility wrappers. Update Node HTTP wiring to use the service; preserve response/error/idempotency behavior. Generate contracts only if a real public contract changes.

## Acceptance and commands

Golden commitment/proof bytes must be identical across adapters and before/after extraction. Existing late-review, purchase-credit, final-review and retry scenarios must retain their expected results. Inject a repository failure and verify the service cannot return accepted success. Check the workerd-facing import graph with a local bundle test; do not infer portability from TypeScript alone.

Existing checks, repository root:

```text
node --test platform/domain/earn/*.test.mjs platform/earn/*.test.mjs platform/contracts/*.test.mjs
node platform/contracts/generate.mjs --check
```

Proposed checks to implement:

```text
node --test platform/application/contract.test.mjs platform/security/canonical.test.mjs
```

## Completion, limits and recovery

Record changed boundaries, exact vectors, source commit and passing commands in task evidence. No economic output change is acceptable without a separately reviewed defect. A port declaration alone is incomplete: Node behavior must exercise it. Keep wrappers until downstream tasks migrate.

All work is local emulation, with zero paid calls, remote writes, provisioning or deployment. Financial flags remain false. If portability requires a dependency, first establish why installed tooling is insufficient; do not replace the stack. On failure retain the old adapter path and fix the smallest extraction boundary. Migration numbers, if unexpectedly needed, are coordinator-assigned `022+`; never fill `019` or modify historical migrations.
