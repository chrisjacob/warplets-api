## Captured program replay

The Linux CI job reads one public programdata account, verifies the program address, metadata and recorded hash, then passes those bytes to an offline SVM. It uses local keys and a new, zero-fee **simulated** global config. The public reference farm is used only for evidence. Use the same pinned October dependencies as the Meteora replay. Run `node platform/lab/fetch-kamino-replay-elf.mjs /tmp/kamino.so` followed by `node platform/lab/replay-kamino.mjs /path/to/october-reference /tmp/kamino.so`. The bytecode is not distributed with this repository. An unavailable public endpoint, changed digest or differing authority fails verification.

The test funds exactly 5% of an illustrative supply with a whole-unit rate of 1,000,000 base units per second. It checks idle time, ten seconds of accrual, harvest with principal still staked, immediate unstake/withdraw/restake, rejection of a nonadmin rate change, and end-of-campaign recovery with a still-unclaimed user balance. It records the simulated fees and recovered amounts only after all receipts and vault balances reconcile. The fee payer, farm admin and user sign their required instructions locally. Before retrying an ambiguous signature, inspect its status and associated balances. Configuration, funding and recovery need distinct owner permissions and persistent operation IDs before a mainnet adapter.

The published instruction layouts were independently encoded for interoperability with the deployed program. Program source is not incorporated into the product or test. Running a test against an allocated binary still requires appropriate use review before commercial deployment. A successful whole-rate fixture does not establish arbitrary precision schedules: fortify frequency, fractional-rate rounding and costs before enabling a different supply/decimal configuration.
