# Verifiable draw feasibility

This optional local adapter replaces an operator-supplied ticket with an independently verifiable signed beacon for a collection that opts in before any reservation. Install the pinned package inside this directory and run its tests. The checked-in round 30,000,000 fixture came from the [public quicknet relay](https://api.drand.sh/52db9ba70e0cc0f6eaf7803dd07447a1f5477735fd3f661792ba94600c84e971/public/30000000). Verification uses the [published chain key and schedule](https://docs.drand.love/blog/2023/10/16/quicknet-is-live/) and the [official signature scheme](https://github.com/drand/drand-client/blob/master/lib/beacon-verification.ts).

Publish a fixed list of 1,000 unique asset IDs, ordered by reserved Level and ordinal, and three weighted trait catalogs with `node cli.mjs publish terms.json`. Registration pins the catalog hash, scheme, chain and delay before accepting any mint in that inventory. Each accepted request binds its subject, owner, original commitment and admission timestamp to the first scheduled round at least 30 seconds later. Verify that precise round with `node cli.mjs settle round.json OP_ID`. Verification and settlement use local files, make no network requests and never pay for a mint. The 30-second minimum is a pilot engineering parameter.

A replay selects the same weighted outcome, traits and asset ID. Later admissions wait for earlier commitments; a withheld proof keeps the original request pending. A manual fulfillment is rejected on a protected inventory. The tests exercise a real threshold signature, wrong-chain/round and altered-proof negatives, concurrent inventory conservation, and protection against supplying a preferred rare ticket. Future enrollment of this candidate remains a product gate.

This proves reproducible local selection. Before a paid sale, enforce the admission time and ordering, irrevocable payment commitment, slot-ID authority, timeout/refund and permissionless fulfillment at a trusted boundary. A database administrator could otherwise backdate acceptance or withhold a result. Threshold compromise and beacon interruption remain dependencies. No private asset key is supplied by this adapter, and no on-chain verification cost has been assumed.
