# Exact input quote rehearsal

The quote endpoint uses the registered ATT/OG identities, immutable supply manifest, a pinned OG feed, and one finalized local capture of the DAMM v2 pool, both legacy SPL mints, both token vaults and the OG price observation. Captures expire after 30 seconds. Every account and the price observation must have the same context slot and timestamp. New incomplete evidence holds the market even while an older observation is still young.

The supported policy is concentrated DAMM v2 with ATT in token A, OG in token B, OnlyB collection, timestamp activation, zero dynamic/compounding fees and the approved 90-to-1 schedule. Raw account checks include the pool owner and discriminator, exact layout length, mint identities, vault wiring and authority, decimals, enabled state and mint/freeze authority removal. Current ATT supply may be lower than its immutable original supply after burns. Unsupported configurations return a reason.

All token math uses BigInt. A buy pays the trading fee from OG input, rounding that fee upward. A sell pays the fee from OG output. Range movement and output rounding match the pinned SDK. Minimum output rounds upward at the requested slippage boundary, retaining the reviewed protection. Maximum requested slippage in this local pilot is 500 basis points. Price impact compares fee-excluded pool output with the pre-trade spot quote. Effective buy FDV uses original supply times gross OG spent divided by ATT received, valued at the observed OG/USD price. The separate spot FDV uses current pool price before trading fees. Both are micro-dollar strings. Price movement, liquidity and the executable route still require a fresh real adapter before financial release.

Quote expiry is the earliest of evidence expiry, 15 seconds after the request, and the next fee-schedule second while the opening fee is declining. The response names the evidence slot, observation time and digest. Network and ATA costs are explicitly unavailable until a transaction simulation provides them. The endpoint creates no transaction intent and exposes no submit control.

From `platform/`, register a quote source and import a capture:

    node quotes/operator.mjs source approved-feed.json
    node quotes/operator.mjs capture account-capture.json

The source file supplies `marketId`, `ogFeed` and `sourceRef`. It is immutable for that local market. The capture supplies `id`, `marketId`, `network:"solana-local"`, `observedMs`, positive `slot`, `finalized:true` and `investigationOpen:false`. Account records `pool`, `attMint`, `ogMint`, `attVault` and `ogVault` contain `address`, `owner`, base64 `data`, `slot`, `observedMs`, `finalized:true` and a `sourceRef`. The `og` record has the same provenance fields, `mint`, `decimals`, approved `feed`, `priceMicros`, `confidenceMicros` and `investigationOpen:false`. The confidence limit is 1% for this pilot. `fixtures.mjs` makes a synthetic example, clearly tagged as fixture data.

Use `GET /api/v1/markets/{id}/quote-status` to discover availability. `POST /api/v1/quotes` accepts `marketId`, `direction:"buy-att"|"sell-att"`, decimal-string `inputUnits` and integer `slippageBps`. The browser receives the same result through the generated versioned client.

Verification:

    node --test quotes/quotes.test.mjs
    node quotes/make-sdk-vectors.mjs /path/to/pinned/meme-protocol --check

The checked-in 80-case fixture was generated by the genuine `@meteora-ag/cp-amm-sdk@1.5.1` from synthetic account bytes, without an RPC connection. It exercises both swap directions, fee second boundaries, nonmatching decimals, dusty amounts and price-range rejection. The local BigInt implementation matches SDK output, price movement and total trading fees. Existing offline program replays separately exercise initialization and buy/sell fees. Comparing every quote against pre-swap captured VM account bytes remains a release gate until that hook is completed. No fixture proves oracle authenticity, actual RPC finality or a funded real pool.
