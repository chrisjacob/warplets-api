# Overnight security baseline

The Snap wrappers still pin Satori 0.10.x upstream. A parent-scoped override selects fixed Satori 0.33.5 for both installed wrapper versions. The actual renderer and each wrapper produce a PNG in isolated, network-disabled processes with a pinned OFL Inter font. Hono Node server 2.1.3 replaces the affected 1.19.x local adapters; a real loopback server verifies the fetch contract. No deployment occurs.

`pnpm security:test:rendering` joins the launchpad CI security gate. The lockfile retains `minimumReleaseAge: 1440` and `blockExoticSubdeps: true`. Initial resolution encountered pnpm's cached-metadata exotic-subdependency bug; lockfile-only resolution with `--prefer-offline` succeeded without disabling protections.

The production audit now reports zero unignored moderate/high/critical findings. Deepmerge 4.3.1 remains an unpatched low advisory under vanilla-extract CSS tooling; launchpad domain code does not import it. Existing browser-installer high exceptions are unchanged. This is exposure assessment, not a fix to that dependency. Reassess before accepting externally supplied build configuration or promoting that tool graph into a runtime. Broader development-tool findings remain in the readiness inventory.

Public card rendering must accept server-derived, bounded content and approved image sources only. Patched SVG rendering does not replace SSRF protections. Application/signing graphs remain independent of the protocol lab.
