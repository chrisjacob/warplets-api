# Performance, security and interface review

Reviewed the complete local milestones 1–3 stack on 30 October 2026. Changes are on `codex/10x-review-improvements`, stacked after settlement. No deployment, remote resource, database migration or provider-budget change is involved.

## Implemented findings

| Finding | Improvement and evidence |
|---|---|
| Wallet/provider code participated in startup before Connect was opened. | A light account button loads the existing shared Connect implementation on demand. Static startup JS + CSS fell from 95,579 bytes (93.3 KiB) to 70,290 bytes (68.6 KiB) gzip, approximately 26.5%. An 80 KiB build budget also rejects wallet components in the static entry graph. The provider remains mounted after first use to preserve wallet sessions. Slow loads can be cancelled; failed chunks show a contained reload action. |
| Polls continued in hidden tabs, could overlap, and could restore an obsolete account's response. | Visibility-aware polling stops hidden work; cancellation and generation checks discard superseded responses. Account changes clear private state. Requests time out after 15 seconds using portable AbortController APIs. Deferred-response and cancellation/timeout regressions pass. |
| Final dashboards replayed the holding ledger and decoded complete private voter payloads on every refresh. | Final dashboards read immutable settlement inputs and aggregate frozen vote weights in SQLite. Public rankings project only their public fields. The finalized-state regression verifies the same weighted result, no ledger/eligibility reads, and at most 12 statements. |
| Vite 6.4.3 had published development-server advisories, including Windows editor command injection. | Pin Vite 6.4.5 in the launchpad, existing app and shared Connect package; regenerate the root lockfile with dependency-age and exotic-dependency protections retained. The final audit reports zero Vite advisories. |
| Local pages lacked anti-framing headers; cross-origin read intent was not explicitly rejected. | Add framing, referrer and permission headers to local UI/preview and API responses; disable cross-origin dev-source access; reject cross-origin/Fetch Metadata API reads alongside existing mutation Origin checks. Live HTTP tests verify these headers, cross-site API 403, and denial of a harmless private-file canary with plain, raw and import query variants. |
| A large introduction and repeated technical explanations pushed the actual round below the first phone screen. | Compact Today / Rewards / History navigation, localized times, clear voting status, one connection action, folded score/receipt details and exact grouped token amounts. Upcoming and closed rounds use appropriate labels. History uses candidate names. |
| Connect presented optional wallets before the required identity; wallet details and unrelated promotions crowded the flow. | Reuse the shared UI with Farcaster first, Solana reward wallet next and optional Warplet boosts last. Fold advanced holding-wallet controls and suppress promotions only for the launchpad. Shared-app defaults remain available. |
| Dialog and tab keyboard behavior was incomplete. | Add modal focus containment, Escape dismissal and focus restoration, with nested wallet/sign-in dialogs retaining control. Tabs support arrows, Home/End and correct panel relationships. Verify both directions of modal focus wrap in the compiled production preview. |

## Validation

- 34 launchpad tests pass, including real SQLite migration replay, cryptographic identity proofs, full HTTP participation/settlement journeys, precise reward totals, stale-response rejection, API cancellation/timeouts and security/performance regressions.
- Frontend/Worker typechecks, import boundaries, production frontend build, startup budget and Worker dry run pass. Worker routing remains local-only.
- All 853 existing app tests pass with two local workers. The initial parallel local run timed out on the unchanged 5-second Network decompression test; bounded concurrency passes without changing tests or timeouts. The existing app build, 235.1 KiB startup budget and production routing checks also pass. CI repeats the frozen-lockfile installation and compatibility build.
- Root typecheck, security preflight, blocklist, redirect and Solana dependency checks pass.
- Desktop and 390×844 browser checks cover Today, Rewards, History, compact Connect, missing-wallet feedback, arrow/Home navigation, Tab/Shift+Tab, Escape and returned focus. No horizontal overflow was observed. Real-account signing and physical-wallet QA remain later manual checks.
- Metrics above measure the production static entry graph and API statements. DevTools tracing was unavailable, so this review does not assign Lighthouse or Core Web Vitals scores.

## Remaining gates

The whole-workspace development dependency audit still reports 60 high, 65 moderate and 21 low findings across existing tooling graphs, including Wrangler/Miniflare, browser-extension tooling and test dependencies. This change adds no audit exceptions. The production audit retains its previous five findings: two ignored high browser-installer advisories, two moderate and one low. Broader tooling remediation needs its own compatibility review.

Live-round scoring still derives provisional aggregates from the current cohort. Materialized aggregates, production traffic/load tests, complete-history indexing, independent acquisition-price verification, real mobile-wallet signing and the existing economic/abuse decisions remain production gates. Explicitly review embedding hosts before enabling any future Mini App deployment. Launch execution, funding and claims remain disabled.
