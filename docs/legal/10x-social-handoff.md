* Retention and choices: separates browser clearing, sign-out, permission revocation, deletion of Code Hunt records, upstream account deletion and public-content removal. * Terms: adds Social-specific account/permission, publication, moderation/reporting, Mini App, wallet, dependency and fee provisions. Limits Social's content licence to service operation; private communications receive no promotional licence. Preserves MIT/open-source permissions and notices, 18+ eligibility, NSW/Australian governing law and mandatory consumer rights.

### Collector evidence, provider statements and limits

The client agent fetched the integrity-matching served collector (reported JS version `2026.10.1`, SHA-256 `637381256384554e1cc3309a62fb238a51b83e7f10b2a56d8ba15dbc73ca762e`) and exercised it in an isolated Node VM with synthetic browser APIs. HTML configuration showed `version=2024.11.0`, `r=1`, SPA mode `spa=2` and one public site token, without a custom send/forward or serverTiming option in that configuration. Other runtime overrides were not established. The token is a public site identifier, not an account credential. No real user data or network request was sent by the harness; these checks do not establish server acceptance, stored records or dashboard visibility.

The collector constructs page/referrer origin and path, navigation/event types, timestamps, script/site identifiers and random page-load IDs; performance timings, transfer/body sizes, available heap statistics and Web Vitals; and diagnostics including selectors, layout rectangles, interaction types and LCP resource URLs/sizes/timings. Browser/engine information and supported OS client hints may also be present. Cloudflare documents country, device, browser and OS reporting dimensions, but this account's dashboard values were not inspected.

Page/referrer fields have credentials, query strings and fragments removed in the reviewed collector. LCP resource URLs bypass that cleanup: the synthetic `?review=synthetic#fragment` value survived in a constructed payload. This establishes a possible collector path, not a real secret transmission. Profile/cast paths and DOM IDs/classes can identify people or content. Keep credentials/private text out of resource URLs and selectors, and inspect actual authenticated payloads rather than promising universal URL redaction.

With the observed config, collection targets same-origin POST `/cdn-cgi/rum`, independently of Farcaster's `/~api` relay; initial load uses XHR and hidden-page vitals use sendBeacon where supported. No blanket API-body, message-text, form-value, session-replay or FID payload collection was found in this collector. That is a script-limited finding, not a promise excluding identifiers in URLs/selectors or other integrations' processing.

The served collector and synthetic paths did not access cookies, localStorage, sessionStorage or IndexedDB. Existing cookies can still accompany a same-origin HTTP request automatically, and Social uses operational storage separately. Cloudflare states its RUM beacon avoids browser storage/fingerprinting and discards received source IP addresses at its edge instead of retaining them in RUM's core databases/logs; those product-specific statements do not extend to CDN/security/API logs. Processing may occur outside the visitor's country.

Cloudflare's FAQ distinguishes unsampled seven-day data from later aggregation/sampling and six months of accessible analytics. Reporting availability is not a guarantee of deletion from all records, exports or backups. The FAQ's statement that query strings are not logged is a provider logging statement, not proof that every client diagnostic field is redacted. Do not infer an EU exclusion or Australia-only processing from product defaults.

Web Analytics configuration access previously returned HTTP 403 with the existing Wrangler OAuth login. Resource association, account roles, geographic rules, exports and actual retention arrangements still require account-owner confirmation. Missing dashboard access or unset hosting build variables do not establish absent collection or change the instruction to retain analytics. No permissions or account settings were changed.
